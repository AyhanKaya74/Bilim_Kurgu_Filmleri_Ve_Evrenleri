# BilimKurguArşivi - Kült Bilim Kurgu Filmleri Rehberi

## Proje Amacı
Bu proje, BPR201 İnternet Tabanlı Programlama dersi Haftalık Proje Ödevi - 2 kapsamında geliştirilmiştir. Sinema tutkunları ve bilim kurgu izleyicileri için kült haline gelmiş 9 bilim kurgu filmini ve evrenlerini tanıtan, kullanıcıların film başlıklarına göre anlık arama yapabildiği üç sayfalık statik bir web sitesidir.

## Sayfa Yapısı
* **Ana Sayfa (`index.html`):** Site tanıtımı, hedef kitle bilgisi ve içerikler sayfasına yönlendirme.
* **İçerikler (`icerikler.html`):** 9 kült bilim kurgu filmine ait kartlar (başlık, kısa açıklama, yönetmen ve vizyon yılı bilgisi) ve başlığa göre canlı arama/filtreleme arayüzü.
* **Hakkında (`hakkinda.html`):** Konunun seçilme gerekçesi ve sitenin ziyaretçilere sağladığı faydalar.

## Çalıştırma Adımları
1. Proje dosyalarını bilgisayarınıza indirin veya GitHub deposunu klonlayın.
2. Herhangi bir sunucu veya veritabanı kurulumuna gerek yoktur.
3. Ana klasörde bulunan `index.html` dosyasına çift tıklayarak projeyi doğrudan modern bir web tarayıcısında (Chrome, Edge, Firefox vb.) açabilirsiniz.
4. Alternatif olarak VS Code veya GitHub Codespaces üzerinde **Live Server** eklentisi ile çalıştırabilirsiniz.
